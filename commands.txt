================================================================================
HOTEL MANAGEMENT SYSTEM - COMPLETE STEP-BY-STEP EXECUTION GUIDE
================================================================================

IMPORTANT NOTE ON DIRECTORY PATHS:
- All commands below are meant to be run from the main project folder:
  `Hotel-Management-System-DBMS`
- If your terminal is already inside the `backend` subfolder, either:
  a) Type `cd ..` to return to `Hotel-Management-System-DBMS`, OR
  b) Run `python app.py` (without typing `backend/`).


--------------------------------------------------------------------------------
STEP 1: INSTALL REQUIRED PYTHON LIBRARIES
--------------------------------------------------------------------------------
Open terminal in the project directory and run:

pip install flask flask-cors psycopg2-binary

(Optional: If using a Virtual Environment)
python -m venv venv
.\venv\Scripts\activate.bat
pip install flask flask-cors psycopg2-binary


--------------------------------------------------------------------------------
STEP 2: SETUP & INITIALIZE THE POSTGRESQL DATABASE
--------------------------------------------------------------------------------
Make sure PostgreSQL is running on your computer.

Command 2A (Creates 'hotel_management' database & tables automatically):
python backend/init_db.py

Command 2B (Verifies database connections & sample query execution):
python backend/test_db.py


--------------------------------------------------------------------------------
STEP 3: START THE BACKEND FLASK API SERVER
--------------------------------------------------------------------------------
Start the backend server:

If you are in project root (Hotel-Management-System-DBMS):
python backend/app.py

If you are inside the backend directory (Hotel-Management-System-DBMS\backend):
python app.py

Backend will start running at:
http://127.0.0.1:5000/

Keep this terminal window running in the background!


--------------------------------------------------------------------------------
STEP 4: OPEN & RUN THE FRONTEND WEBSITE
--------------------------------------------------------------------------------
Open a NEW terminal window or file explorer:

Option A (Direct Browser):
Double-click "index.html" (or open "register.html" / "login.html") in your browser.

Option B (Using Local Web Server):
python -m http.server 8000

Then open in your browser:
http://localhost:8000/


--------------------------------------------------------------------------------
STEP 5: VERIFY SAVED CUSTOMER DATA IN DATABASE
--------------------------------------------------------------------------------
After registering a new guest on the frontend website:

Option A (Run terminal verification script):
python backend/verify_customers.py

Option B (Check live API endpoint in browser):
http://127.0.0.1:5000/api/customers
